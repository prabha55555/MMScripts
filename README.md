## 🚀 Get Started in 3 Steps

### 1. Navigate to Project
```bash
cd mmscripts-app
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

**Open your browser**: http://localhost:5173

**That's it! Your website is running! 🎊**

## 🎨 Features

### Professional Design
- Modern, clean, emotion-driven
- Vivid Blue (#014aad) brand colors
- Smooth animations
- Mobile-first responsive

### Complete Pages
1. **Home** - Hero, services, community
2. **About** - Story, vision, mission
3. **Services** - 10 publishing services
4. **Books** - Showcase catalog
5. **Articles** - Blog section
6. **Achievements** - Milestones & success
7. **Team** - Member profiles
8. **Contact** - Form & info

### Tech Stack
- **Frontend**: React 19.2, Vite 7.2
- **Styling**: Tailwind CSS 4.1
- **Animations**: Framer Motion 12.23
- **Routing**: React Router 7.10
- **Backend**: Firebase 11.1 (optional)
- **Deployment**: Vercel (ready)
